# best-odds

Materiale per la produzione di background grafici dei banner "best odds" (quote) per operatori betting.

- `.claude/skills/best-odds-backgrounds/`: skill Claude Code con il workflow completo (analisi stile operatore, ricerca identità torneo, intervista guidata, generazione con Higgsfield MCP, QA, ciclo di feedback).
- `deliveries/`: indici di consegna delle sessioni (link alle immagini generate e alle reference usate).
